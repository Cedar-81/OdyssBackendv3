Some keywords you should know
Playbook: A Playbook in Odyss is a travel dashboard. It contains all the information regarding a trip and this is also where all the planning happens. It contains checklists, itineraries, accomodation, transportation e.t.c
Wallet: This is a wallet that is tied directly to the budget created for a Playbook and is where spendings happens. When a user account is created they are assigned a Wallet and an abstaction of it called a Pocket is created for each Playbook such that money assigned to the Pocket of a particular Playbook can't be used by another.
